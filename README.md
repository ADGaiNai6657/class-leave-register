# 班级请假登记

一个**只在本机运行**的班级花名册请假登记小工具，支持 **macOS 与 Windows**。

把花名册里的所有学生平铺成卡片，双击卡片填写请假理由与是否补假，最后把结果复制到剪贴板，
或复制到剪贴板并导出 CSV。

- 前端：**纯 HTML + CSS + JavaScript**（无框架、无构建步骤）
- 后端：**Node.js 内置模块**（`http` / `fs` / `child_process` / `zlib`）
- 第三方依赖：**零**（`package.json` 的 `dependencies` 为空，**不需要** `npm install`）
- 数据流向：**全部在本机**。不联网、不写数据库、关闭程序即丢失本次填写内容

> **隐私承诺：本仓库只包含程序代码、测试与文档，不含任何真实学生信息。**
> 花名册属于真实个人数据，`.gitignore` 已按支持的每一种格式逐一排除（详见
> 「[九、隐私与安全](#九隐私与安全)」）。**请不要把花名册提交到版本库。**

## 一、快速开始

### 1. 准备环境

安装 [Node.js](https://nodejs.org/) **18 或更高版本**即可，无需其它依赖。

```bash
node -v          # 确认能打印 v18.x 及以上
```

### 2. 放好花名册

把你的花名册文件放到**应用所在文件夹**（或其上一级文件夹，或其中的 `花名册/`、`roster/` 子目录）里，
应用启动时会自动扫描。支持 `.xls` / `.xlsx` / `.csv` / `.tsv` / `.txt` / `.json`。

### 3. 启动

**方式一：双击启动（推荐）**

| 系统 | 双击这个文件 |
| --- | --- |
| macOS | `启动班级请假登记.command` |
| Windows | `启动班级请假登记.cmd` |
| Linux（可选） | 给 `启动班级请假登记.command` 执行权限后运行 |

会弹出一个终端 / 命令行窗口，并自动用**系统默认浏览器**打开界面。关闭该窗口即退出程序。

> - macOS 首次双击若提示“来自身份不明的开发者”，右键该文件 → 打开 → 打开即可。
> - Windows 若双击无反应，可右键 → 以管理员身份运行，或改用下面的命令行方式。

**方式二：命令行**

```bash
cd 班级请假登记
npm start          # 等价于 node server.js
```

### 4. 命令行参数

```bash
node server.js --roster ../某花名册.xlsx     # 手动指定花名册（默认自动扫描）
node server.js --port 8080                   # 指定端口（默认自动选空闲端口）
node server.js --export-dir "D:\文档"         # 指定导出目录（默认项目根目录）
node server.js --title 本某某班               # 指定导出文本首行标题
node server.js --no-open                     # 只启动服务，不自动打开窗口
node server.js --help                        # 查看帮助
```

> 路径按平台习惯书写：macOS / Linux 用 `~/Documents`，Windows 用 `D:\文档`
> （命令行走 `cmd` 时，含空格的路径建议加引号）。

服务只监听 `127.0.0.1`，局域网内其它设备访问不到。

## 二、使用说明

1. **卡片网格**：启动后按花名册顺序平铺所有学生，姓名直接来自花名册文件，没有写死。
2. **卡片大小**：右上角 `卡片大小：小 / 中 / 大`，切换后卡片尺寸与同屏人数立即变化。
3. **双击卡片**：向下展开，出现「请假理由」文本框与「是否补假？」是 / 否单选按钮。
   再次双击卡片空白处（或点「收起」）即可收起，**已填内容不会丢失**，可以继续修改。
4. **编辑状态**：填写过的卡片变为浅绿色并显示「已填写」标签，姓名下方给出摘要
   （如 `身体不适，需要休息 · 补假：否`）；底部状态栏显示 `已填写 N / 总数`。
5. **导出**：点右上角「导出」弹出浮窗，两个选项：
   - **复制到剪切板**：生成 Tab 分隔文本（首行标题，次行表头 `姓名 请假理由 是否补假`），
     可直接粘贴到聊天窗口，粘到 Excel / Numbers / WPS 会自动分列。
     字段内部的换行与制表符会被归一为空格，避免破坏行列结构。
   - **复制到剪切板，并输出 CSV**：同时写剪贴板，并在导出目录生成
     `请假登记-年月日-时分秒.csv`（UTF-8 带 BOM、CRLF 换行，Excel / Numbers 打开中文不乱码）。
     成功后浮窗显示完整路径，并提供「在文件夹中显示」
     （macOS 打开访达并选中，Windows 打开资源管理器并选中）。重复导出不会覆盖，而是生成带序号的新文件。
6. **导出范围**：**只保留请假的学生**。判定标准与界面「已填写」一致：*填了请假理由* 或
   *选择了是否补假*，满足其一即导出；一个人都没填时，导出内容只有标题和表头。
   没有选择「是否补假」时该字段留空，不会替你编造“否”。
7. **首行标题**：剪贴板文本与 CSV 的**第一行都是标题**，第二行才是表头。
   取值顺序：`--title` 参数 → 环境变量 `CLASS_LEAVE_TITLE` → 本地配置 `local-config.json`
   → 中性默认值 `本班请假登记`。
8. **关闭程序**：直接关闭终端 / 命令行窗口。填写内容只存在内存里，不留任何持久化数据。

## 三、导出标题（真实班级名怎么放）

真实班级名请只写在本地的 `local-config.json`（该文件已被 `.gitignore` 排除，不会进入版本库），
这样双击启动也能得到你自己的班级标题，而仓库里不留任何班级信息：

```json
{ "title": "本某某班" }
```

格式见仓库中的 `local-config.example.json`。也可以用 `--title` 参数或环境变量 `CLASS_LEAVE_TITLE`
临时指定，二者优先级更高。

导出示例（剪切板文本，`→` 表示 Tab；标题与姓名均为虚构）：

```text
本某某班
姓名→请假理由→是否补假
张三→身体不适，需要休息→否
李四→参加考试，需要"提前"离校 并复诊→是
```

对应 CSV（Excel / Numbers 打开后第一行为标题，第二行为表头）：

```csv
本某某班
姓名,请假理由,是否补假
张三,身体不适，需要休息,否
李四,"参加考试，需要""提前""离校
并复诊",是
```

## 四、支持的花名册格式与识别规则

| 格式 | 说明 |
| --- | --- |
| `.xls` | Excel 97-2003（BIFF8 / OLE2，含 WPS 生成的文件） |
| `.xlsx` | 现代 Excel（ZIP + XML，用内置 `zlib` 解压） |
| `.csv` / `.tsv` / `.txt` | 自动嗅探分隔符（`,` `TAB` `;` `\|`），支持 RFC4180 引号转义与字段内换行 |
| `.json` | 对象数组（含 `姓名` 字段）或字符串数组 |

**编码**：UTF-8（含 BOM）、GBK、UTF-16LE 自动识别。

**姓名列定位顺序**：

1. 在前 12 行中查找标题为 `姓名 / 名字 / 学生姓名 / name` 等的列；
2. 若没有表头，按「像姓名的比例、唯一性」自动识别，并在界面明确提示「已自动识别第 N 列为姓名列，请核对」；
3. 仍无法可靠判断时报错，**绝不擅自猜测**。

## 五、跨平台说明

系统相关操作全部按平台自动选择命令，macOS 与 Windows 上是**同一套代码、同一套玩法**：

| 能力 | macOS | Windows | Linux（可选） |
| --- | --- | --- | --- |
| 写 / 读剪贴板 | `pbcopy` / `pbpaste` | PowerShell `Set-Clipboard` / `Get-Clipboard` | `wl-copy`/`wl-paste` 或 `xclip` 或 `xsel` |

| 双击启动脚本 | `.command` | `.cmd` | `.command` |

> Windows 下剪贴板通过系统自带 PowerShell 读写；其中文不会乱码（写入时经临时 UTF-8 文件转交，

代码位置：`lib/clipboard.js`（剪贴板）、`lib/system.js`（打开浏览器 / 定位文件）。

## 七、为什么不用 Electron / Tauri

| 方案 | 结论 |
| --- | --- |
| Tauri | 需要 Rust 工具链，需额外安装整套工具链 |
| Electron | 会引入约 200MB 运行时，二进制要从 GitHub 下载，体积与耗时都不划算 |
| **Node 内置模块 + 本地浏览器窗口（本项目采用）** | **零依赖、秒级启动**；Node 内置 `http`、`zlib`、`TextDecoder`、`fetch`，并可直接调用各平台自带命令，足够完成全部需求 |

因此本应用由一个只监听 `127.0.0.1` 的本地小程序负责「读花名册 / 写剪贴板 / 写 CSV」，
界面仍是标准 HTML + CSS + JavaScript，用**系统默认浏览器**打开（不锁定任何浏览器）。

如果想打包成 `.app`（macOS）或 `.exe`（Windows），可自行加装 Electron（本项目代码**无需改动**）：

```bash
npm install --save-dev electron @electron/packager
npx @electron/packager . 班级请假登记 --platform=darwin --arch=arm64 --overwrite   # macOS
npx @electron/packager . 班级请假登记 --platform=win32  --arch=x64   --overwrite   # Windows
```

## 八、异常处理（都不静默）

| 情况 | 表现 |
| --- | --- |
| 找不到花名册 | 顶部红色提示，列出所有搜索目录，并提供「重新扫描花名册」 |
| 找到多个像花名册的文件 | 明确列出候选，界面给出「使用 xxx（N 人）」按钮让你选，绝不擅自猜测 |
| 格式无法解析 | 提示具体原因（例如扩展名是 `.xls` 但内容不是旧版 Excel，建议另存为 `.xlsx` 或 `.csv`） |
| 找不到姓名列 | 提示无法识别，并说明请在花名册中把姓名列标题写成「姓名」 |
| 没有表头但能识别姓名列 | 正常显示，同时在顶部提示「已自动识别第 N 列为姓名列，请核对」 |
| 空姓名 / 重复姓名 | 空姓名行跳过并提示；重复姓名保留两张卡片并提示 |
| 没有人填写请假信息 | 导出浮窗提前提示「导出内容将只有标题和表头」；点「复制到剪切板」返回明确提示，CSV 仍可导出 |
| 导出目录不存在 / 无写入权限 | 导出浮窗显示明确错误（如「没有写入权限，无法导出到：…」） |
| 剪贴板写入失败 | 导出浮窗显示明确错误（CSV 仍会写出，并单独提示剪贴板失败） |

## 九、隐私与安全

**设计原则：一切都在本机，且不产生任何版本库泄漏。**

- **花名册只读**：本应用从不修改、移动或删除花名册文件；
- **不出网**：代码里没有任何对外请求；服务只监听 `127.0.0.1`；
  端到端测试抓取了页面全部网络请求，确认只访问本机服务；
- **无遥测**：没有埋点、统计、日志上报；
- **不落盘**：填写内容只在内存；唯一的写文件动作是「导出 CSV」且**只由用户点击触发**，
  目录固定为导出目录，导出的 CSV 已被 `.gitignore` 排除；
- **定位文件受限**：「在文件夹中显示」只允许打开导出目录内的文件；
- **不执行文件内容**：页面对所有来自花名册的文字都用 `textContent` 写入；
- **CSP 收紧**：界面启用 `default-src 'self'` 等安全响应头，关闭 `nosniff` / `frame-ancestors` 等风险面。

### `.gitignore` 如何保护花名册（逐一排除每种格式）

花名册支持 6 种格式，`.gitignore` 把每一种都排除，宁可多排除也不漏：

| 排除规则 | 覆盖对象 |
| --- | --- |
| `*.xls` `*.xlsx` `*.xlsm` `*.xlsb` | Excel 电子表格花名册 |
| `*.csv` `*.tsv` `*.txt` | 分隔文本 / 纯文本花名册，以及所有导出的登记 CSV |
| `*.json`（白名单放行 `package.json`、`local-config.example.json` 等） | JSON 花名册；配置文件则逐一放行 |
| `*花名册*` `*名单*` `*roster*` | 带关键词、扩展名不限的花名册 |
| `/请假登记-*.csv` `/local-config.json` | 导出的登记结果、含真实班级名的本地配置 |
| `test/screenshots/` | 端到端测试截图（画面里含真实学生姓名） |

> 花名册文件名**不一定**含「花名册」等关键词（例如 `初三2班.xls`、`2024级名单.csv`）；
> 因此不能只靠关键词，必须按扩展名整体排除——这正是上面同时使用「扩展名」与「关键词」两组规则的原因。

**提交前自检**：

```bash
git status --ignored          # 确认花名册、截图、local-config.json 处于 ignored 状态
git ls-files                  # 确认版本库里没有任何数据文件（.xls/.csv/.json 数据等）
```

## 十一、已知问题与限制

1. 界面语言、数字格式等按中文班级场景设计，未做多语言。
2. 花名册人数上限保护为 5000 人（超出会拒绝解析，避免误读大表）。
3. `.xls` / `.xlsx` 解析器是「最小实现」，只覆盖花名册这类简单表格：
   不支持宏、图表、合并单元格语义、公式计算（只读取单元格里已存的值）；
   若某个 `.xls` 结构特殊导致读取失败，请用 Excel / WPS / Numbers 另存为 `.xlsx` 或 `.csv` 后重试。
4. `.xlsx` 不支持 ZIP64（超大工作簿），同样建议另存为 `.csv`。
5. 填写内容不做持久化（按需求刻意如此），关闭窗口即丢失；也没有「撤销 / 重做」。
6. 卡片大小与窗口状态不记忆，每次启动都是「中」号。
7. 同一文件夹里同时放了多个花名册文件时，每次启动都需要手动点选一次（不会记忆选择）。
8. 应用用系统默认浏览器打开界面（就是浏览器里的一个标签页）；如需「应用窗口」外观，可改装 Electron。
9. Linux 下剪贴板需自行安装 `wl-copy`/`xclip`/`xsel` 之一，打开浏览器与文件夹用 `xdg-open`；
   **macOS 与 Windows 均无需额外安装任何东西。**

| `*.json`（白名单外） | 防止 JSON 花名册；项目自带配置用白名单放行 |
| `/请假登记-*.csv` | 导出结果是真实学生请假信息 |
| `/local-config.json` | 通常写着真实班级名（导出标题） |
| `test/screenshots/` | 端到端测试截图，画面含真实学生姓名 |
| `.DS_Store`、`Thumbs.db`、`desktop.ini` 等 | 系统自动生成，与项目无关 |
| `test/.tmp/`、`test/.e2e*/`、`test/.chrome-*/` | 测试运行时临时产物 |
| `node_modules/`、`.npm/` | 零依赖，留作保险 |
| `.idea/`、`.vscode/` | 编辑器 / IDE 本地配置 |

也就是说：**版本库里只有程序代码、测试与文档，没有任何真实学生信息。**
